# Real AI Fishing 0.1.9

- Two additional coastal waters: Secluded Cove and Tidal Strand, with native 8K panoramas, authored walkable shores, measured lighting, coastal vegetation and surf ambience. Ten waters are available in total.
- Four additional maritime species: dusky kob, white stumpnose, zebra seabream and Cape horse mackerel. The Field Guide now contains 32 species.
- Undiscovered guide entries show a question mark for both name and icon, plus their usual habitat and preferred bait. Catching a species reveals its identity and details.
- Controls include independent position and rotation adjustments for each controller. Casting retains head-directed targeting and the existing rod-swing mechanics.
- Ground mesh boundaries keep fighting fish clear of solid shores and underwater obstacles. Boundary encounters allow diving or outward runs. Fishing sectors are repositioned into reachable, visible water, and player movement barriers do not block aiming.
- Secluded Cove's foreground water now renders as animated water across the fishable cove.

The BBQ prototype is excluded. Multiplayer remains protocol 3. Linux and Windows x86_64 archives, Quest and Pico ARM64 APKs, notices, a build manifest and SHA256 checksums are provided. Android version code 10 retains the existing signing identity.

Packages retain native 8K panoramas, desktop BC6H panorama compression, lossless lighting atlases, texture deduplication and maximum ZIP/APK compression. Authoring files and development outputs are excluded.

Validation covers casting, controller calibration, all 90 fishing sectors, fish boundaries, guide discovery, scenery, multiplayer and exported assets. Windows and standalone Quest/Pico execution are not tested on the build host.
