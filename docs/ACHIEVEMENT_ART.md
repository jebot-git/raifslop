# Achievement artwork

Generated with the built-in image_gen tool on 2026-09-26. Production files are
[256×256 PNGs](../assets/ui/achievements/art/), each below the EOS 256 KiB limit.
ImageMagick performed only final downscaling and PNG packaging. Superseded
placeholder icons were removed before release.

The game and both portals use six unlocked illustrations and one shared locked
badge. The artwork was inspected for subject, legibility, consistent teal/brass
styling and absence of text. See [ACHIEVEMENTS.example.json](ACHIEVEMENTS.example.json)
for exact icon-to-achievement mapping.
