# 0.1.19-rc.1

This candidate moves the EOS-based game onto main and replaces the archived full-size golf integration with 216 minigolf holes across all twelve water locations. Anglers, cooks and golfers share the same location and multiplayer session. The fitted putter, controller-angle calibration, one-handed play, support-hand snapping and guide scorecards remain available. Ball teleport is optional; hole completion and fitting never reposition the player automatically.

Courses include bank shots, slopes, raised and recessed greens, narrow routes and local decorations. Four offshore courses have moored boats; eight land courses connect through terrain. All courses have baked static lighting and mipmapped textures. Reverse stereo sweeps verified each course against its panorama and informed river-bank and coastal-ground fixes.

Protocol 21 requires matching clients and dedicated servers. New provider leaderboards separate minigolf records from historical full-golf results. Existing achievement IDs remain valid with minigolf descriptions. Old golf destinations are removed.

Validation includes automated putting/terrain/fitting and save migration checks, all-course lightmap checks, native synthetic Monado activity transitions and 180° stereo pans, and three clients simultaneously fishing, cooking and playing minigolf. Synthetic checks do not establish human VR comfort or standalone Quest performance.

Meta candidate: version 0.1.19-rc.1, Android code 26, existing signing identity, RC channel. Publication and upload results are recorded separately after completion.

GitHub distributes the Quest expansion in a lossless ZIP to stay below its per-file limit. Extract the original `main.26.org.jebot.raifslop.quest.obb` for sideloading; Meta RC installs the expansion automatically.
