# CC0 lettering fonts

**Almonte** by Raymond Larabie is the title face for Ultimate Boomer Sim and
UBS. **Blue Highway Regular**, also by Larabie, is the supporting text face.
These are the original OTF files; no new font licence or authorship is claimed.

- Author's CC0 collection: https://typodermicfonts.com/public-domain/
- Exact downloaded archive: https://typodermicfonts.com/assets/downloads/typodermic-public-domain-2024-12.zip
- Files: `OpenType Fonts/Almonte.otf` and `OpenType Fonts/Blue Highway Rg.otf`.
- Downloaded and licence verified: 24 September 2026.
- Dedication: https://creativecommons.org/publicdomain/zero/1.0/

`License.txt` and `License.pdf` are retained verbatim from the archive. The text
file uses Windows-1252 encoding. It explicitly dedicates the included fonts to
CC0. Commercial artwork, embedding and redistribution are permitted. Font files
remain inside this store-media directory and are not installed system-wide.

The game icon remains the original `assets/icon.svg`. The media renderer uses
the same artwork and colours. The opaque store icon fills its transparent outer
corners with the existing teal background; transparent logo exports preserve
the original rounded outline. Store title cards use the full listing name,
Ultimate Boomer Simulator; `logo-lockup.png` and `logo-ubs.png` provide the
requested short lettering. No store-title rename is implied.
