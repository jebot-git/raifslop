# Avatar recovery, coastal scenery and fight feedback (0.1.10)

Avatar transfer now acknowledges accepted/throttled selections, cancels superseded work, retries requests and stalled downloads with bounded backoff, and changes source when another owner can provide an avatar after a disconnect. Per-asset loading errors clear on retry, success or cancellation. Undecodable embedded VRM images are rejected before equipping/caching a partial avatar. See MULTIPLAYER.md for protocol 4 and diagnostics; clients and servers must update together. The live 0.1.9 server has not been modified.

Opt-in client diagnostics measure actual monotonic frame intervals and avatar/location/fish-building stages. Network diagnostics include accepted-state ages/gaps and separate voice decode/FEC-attempt/drop counters. Remote fish visuals are deferred until the player is at the same water and has a visible landed catch.

Coastal Rocks' mooring cleat extends to the terrace. Rear bench uprights move behind the backrests at all five locations using that bench; the authored generator is also corrected. Existing baked UVs and material assignments remain intact. Coastal dune grass, wrack and the 3D pier poster now generate mipmaps. The remaining environment images without mipmaps are menu previews. Hoek Beach uses a wider 172-degree rear projection divided into 120 columns, eight rows per band and five depth bands, reaching 23 metres; photographic walls no longer smear across the flat distant apron in the same way.

Fish stamina and recovery have no new UI meter, label or popup. Exhaustion creates a soft positional ripple and a slow, subtle ring. Renewed strength produces a sharper recorded splash and two faster water rings at the fish. Action changes create their own positional ripple and water pulse. Existing CC-licensed fishing recordings are reused. Cues fire on transitions, pause with fishing controls, and use a bounded audio/mesh pool.

Recovery gives a hidden 0.65-second reaction window. Accumulated strain is preserved; easing off smoothly unloads tension and relieves some strain. Repeated recovery cannot extend an active window. Existing slack loss, inappropriate fly-reel penalties and predator-opening danger remain. Continuing to reel against an already strained line can still snap it within about a second of recovery.

Validation artifacts are in `test-results/quality-update/`. Automated coverage includes rapid avatar selection, explicit rejection, bounded request retry, stalled-download retry, alternate sender, stale-error clearing, decode failure, reaction-window limits, cue transitions, actual imported mip levels, bench/cleat geometry, and aiming/ground boundaries. Render checks cover standing/seated and rear-edge coastal views. Native headset/Windows Virtual Desktop validation is still required; release validation is documented in RELEASE.md.

Final verification: 60 distinct regression suites passed across the full run and targeted reruns, plus dedicated/ad-hoc local multiplayer. Initial audio-teardown errors in two tests were resolved by stopping playback and allowing the mixer to drain before exit. A deliberate 80 ms stall was captured as an 82.384 ms wall-clock frame interval. Linux desktop render captures show the final hidden recovery treatment; this is not a headset or Windows execution claim.
