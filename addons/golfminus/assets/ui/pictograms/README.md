# Golf pictograms

The grip, tracking, menu, left, right, up, warning and stop SVGs are copied unchanged
from the local Real AI Fishing project (`assets/ui/pictograms`, revision 4e5a8a4).
The remaining SVGs are original golf extensions drawn with the same 128px viewBox,
rounded 11px dark outline (#102e24) and 6px mint stroke (#b4e5cf).

Keep identifiers stable: scripts/golf/pictograms.gd caches these textures. Club
silhouettes are paired with club numbers, so irons remain distinguishable.
World prompts retain physical-button labels, measurements and actionable warnings.
